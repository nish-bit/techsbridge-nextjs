## Razorpay Standard Checkout

The Starter and Growth plans create fixed-price orders through Razorpay Standard Checkout. The server selects each plan's amount; requests cannot supply a custom amount. Custom projects remain quote-based. The key secret is only read by the server, and the site reports payment success only after backend signature verification.

For local development, set these values in `.env.local` (or `.env`):

```env
RAZORPAY_KEY_ID=your_razorpay_test_key_id
RAZORPAY_KEY_SECRET=your_razorpay_test_key_secret
```

Use freshly generated Razorpay Test Mode credentials (rotate any secret that was previously shared or committed). Copy `.env.example` to `.env.local` and replace the placeholders. Start the app with `npm run dev`, open the Pricing section, and click **Pay Now** on Starter or Growth. Complete the modal with a Razorpay test payment method; the page reports success only after the backend verifies the payment signature. Configure the same server-side environment variables in your deployment provider before enabling checkout there. Never commit `.env.local`.
