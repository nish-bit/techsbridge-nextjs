# TechsBridge image pack

Copy the `public/images/` directory into the root of your GitHub repository, preserving the folder structure. These are compressed WebP images.

Suggested use (these are not automatically wired into the site):

- hero-workspace.webp — Hero
- about-collaboration.webp — About (illustrative stock-style scene, NOT an actual TechsBridge team photograph)
- studio-team-concept.webp — Optional studio imagery (fictional people, do not label as actual staff)
- product-dashboard-dark.webp — Generic service/product illustration
- product-dashboard-light.webp — Generic service/product illustration
- product-task-app.webp — Generic application design illustration
- product-commerce.webp — Generic ecommerce illustration
- product-responsive-dashboard.webp — Generic responsive software illustration

Important: The product mockups are fictional concepts, NOT real TechsBridge client projects or case studies. Do not attach them to named client projects or imply they represent delivered work. Use actual client screenshots in Portfolio and Case Studies. No client logos or testimonials have been invented.

Example Next.js use: `<Image src="/images/hero-workspace.webp" alt="Laptop displaying a software dashboard in a warm studio workspace" width={1536} height={1024} />`.

All files use a warm neutral/terracotta palette, with no blue accents.
